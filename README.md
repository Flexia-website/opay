# OPay PWA — Multi-User Upgrade

## What's New

### 🗄️ PostgreSQL Database
- All user data, balances, and app state are stored in PostgreSQL (via Render's free DB).
- Falls back to SQLite locally for development (`opay_local.db`).

### 👤 Multi-User System
- **Admin account** (you): Login with password `147852`, PIN `0803`, or fingerprint — unchanged.
- **Normal users**: Can register via the "Create Account" button on the login screen.
  - Each user gets their own balance, account number, and profile.
  - They log in with email + password.
  - They only see their own data — no admin tools visible.

### 🛡️ Role-Based Access
- Admin sees an **"ADMIN TOOLS"** section on the profile (Me) page:
  - **Manage Users** — view all registered users, adjust balances, edit profiles, activate/deactivate accounts, delete users.
  - **Adjust Balance** — the balance adjuster (admin only).
  - **Appearance** — app customization (admin only).
- Normal users see none of these sections — they're completely hidden.

### 👥 Admin User Management (`/admin/users`)
- View all registered users with stats (total users, active count, total balance across all accounts).
- Add users manually (admin can create accounts directly).
- Edit any user: name, email, phone, password, admin notes.
- Adjust any user's balance (set exact / add / subtract).
- Activate or deactivate accounts.
- Delete users.

## Deploying on Render

1. Push this folder to a GitHub repo.
2. In Render Dashboard → **New Web Service** → connect your repo.
3. Render will detect `render.yaml` and create:
   - The web service (Flask app)
   - A free PostgreSQL database
4. Add your Cloudinary env vars in the Render dashboard.
5. Deploy → the app auto-creates all DB tables on first boot.

### Environment Variables
| Variable | Description |
|---|---|
| `DATABASE_URL` | Auto-set by Render from the linked DB |
| `SECRET_KEY` | Auto-generated by Render |
| `ADMIN_USERNAME` | `clinton` |
| `ADMIN_PASSWORD` | `147852` |
| `ADMIN_PIN` | `0803` |
| `CLOUDINARY_CLOUD_NAME` | Your Cloudinary cloud name |
| `CLOUDINARY_API_KEY` | Your Cloudinary API key |
| `CLOUDINARY_API_SECRET` | Your Cloudinary API secret |

## API Endpoints

### Auth
- `POST /api/login` — Admin or user login
- `POST /api/register` — Register new user account
- `POST /api/logout`
- `GET /api/session` — Check current session

### Admin Only
- `GET /api/admin/users` — List all users
- `POST /api/admin/users` — Create user
- `GET /api/admin/users/:id`
- `PATCH /api/admin/users/:id` — Edit user
- `DELETE /api/admin/users/:id`
- `POST /api/balance/adjust` — Adjust any user's balance (add `user_id` to body)
- `POST /api/balance/set` — Set any user's balance

### Authenticated (any user)
- `GET /api/balance`
- `GET /api/state`
- `GET/POST /api/customization`
- `PATCH /api/user/profile` — Update own profile/password/PIN
